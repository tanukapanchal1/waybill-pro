Use Waybill Pro as an App

Run offline on PC, Mac, or Android

1. Download Standalone App File

Save this app directly to your computer or phone. Opening it in Chrome or Edge lets you print directly and keeps all data saved locally.

2. Pin as Desktop / Phone App

Windows / Mac (Chrome or Edge): Open the downloaded file → click Menu (⋮) → Cast, save, and share → Create shortcut (tick Open as window).

Android / iPhone: Open in browser → tap Add to Home Screen.

3. Access as a Live Website (Web + App)

Download Waybill_Pro_App.html, rename it to index.html, and drag-and-drop it onto app.netlify.com/drop (free) to get your own live web link. Connect Google Drive or Firebase Cloud so Web and App share the exact same data.
